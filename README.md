# Appointment Scheduling System

This project implements an Appointment Scheduling System using Java and Maven. 
It follows a layered architecture design and applies key software engineering principles, 
including the Strategy and Observer design patterns.


The project includes comprehensive unit testing using JUnit and Mockito, 
with test coverage exceeding 80% as required.

## Documentation
The code includes detailed documentation (JavaDoc) for key classes and methods.
